# Cinema-Ticket-Booking

A console app that lets users view showtimes, pick seats, and reserve tickets for a cinema.
• Movie: Contains details about a film (title, genre, durationMinutes).
• Showtime: Combines a Movie with a specific time slot and a 2D array (boolean[][] seats) representing available seating.
• Ticket: Represents a confirmed booking, storing the ticketId, chosen seatNumber, and total price.
• CinemaReservationSystem: Manages the list of movies and scheduled showtimes, printing the seat map layout to the console and handling user selections.
